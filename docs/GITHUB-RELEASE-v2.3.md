# Project Reforged Patch Downloader v2.3

This release focuses on polish, reliability, and local patch health.

## New in v2.3

- streamlined final header and cleaner release-ready presentation
- local file verification for tracked patch installs
- `Needs repair` detection for missing or mismatched files
- `Repair Selected` for fast patch recovery
- persistent download and repair history
- release notes shortcut from the patch details area
- hardened parser for Project Reforged page changes
- lightweight regression tests around parser and version checks

## Runtime

This build requires the Windows `.NET 10 Desktop Runtime`.
