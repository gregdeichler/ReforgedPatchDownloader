# Project Reforged Patch Downloader 2.1

## What is new

- rebuilt as a modern WPF desktop app on .NET 10
- live Project Reforged catalog loading from the official site
- patch descriptions, versions, update dates, and file sizes
- update highlighting for downloaded patches
- linked patch rules and single-choice variant safety
- byte-aware download progress
- stop downloads support and exit warning while downloading
- clickable `What Changed` summary
- `Open Installed File` action for local patches
- polished `v2.1` interface and improved release packaging

## Download

Use the `ProjectReforgedPatchDownloader-v2.1.zip` release asset.

## Notes

- the app is for Windows
- point it at your patch folder, refresh the live catalog, then download the modules you want
- official Project Reforged site: https://projectreforged.github.io/
