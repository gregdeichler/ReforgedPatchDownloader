Project Reforged Patch Downloader 2.1

What This Is
- A Windows desktop downloader for Project Reforged patch modules
- Built to make patch selection, update checks, and downloads easier to manage

What It Does
- Loads the live Project Reforged catalog
- Shows patch descriptions, versions, dates, and file sizes
- Highlights downloaded patches when live updates are available
- Handles linked patch sets and conflicting variants safely
- Downloads directly into your chosen folder with visible progress

Main Features
- Search and filter support
- Update tracking manifest
- Clickable "What Changed" panel
- Clean stop for downloads in progress
- Exit warning while downloading

How To Use
1. Run ReforgedPatchDownloaderApp.exe
2. Choose your patch folder
3. Click Check for Updates to refresh the live catalog
4. Select patches or use Select Recommended
5. Click Download Selected
