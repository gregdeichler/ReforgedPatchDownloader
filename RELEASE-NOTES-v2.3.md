Project Reforged Patch Downloader 2.3

Highlights
- New streamlined v2.3 header and cleaner release-ready presentation
- Local file verification for tracked patch installs
- `Needs repair` detection for missing or mismatched tracked files
- `Repair Selected` action for quick re-download and recovery
- Persistent download and repair history
- Release notes shortcut from the patch details area
- Hardened live-site parser with regression tests for heading changes

Core Improvements
- Better trust around local patch state
- Safer visibility into update and repair conditions
- Cleaner release packaging flow for future versions
- Parser refactor into a dedicated testable component

Runtime Requirement
- This build requires the Windows .NET 10 Desktop Runtime
